# Changelog

## 0.2.0-rc1 (2026-08)

- Dataset scientific workspace with Zeiss SEM calibration handling.
- Python SIMPoly source-compatible estimator (known library divergence: `bwskel`).
- Fathom Local cross-section estimator.
- Fathom Field experimental estimator family (EDT / paired edge / intensity profile).
- Oriented Ribbon V1 — experimental refined centerline with re-measurement.
- Per-image and dataset scientific reports with equal-image-weight dataset-wide
  diameter distribution.
- Manual 5×5 reference workflow with autosave.
- Export analysis bundle (CSV / JSON / figures / HTML report / provenance).
- In-app Quick Start, User Guide, Methods Guide and shortcuts.
- Cross-platform release packaging (Linux / Windows / macOS) with build
  provenance.

Scientific status: Fathom Field and Oriented Ribbon V1 are experimental; real
SEM results characterize behavior/agreement, not known absolute accuracy.
